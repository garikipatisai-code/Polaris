## Notes

- M3.5 is empirically validated on real hardware. All 4 slow-tier E2E tests pass against qwen3.5:4b on the P2200.
- The earlier concern about 333 vs 301 mock test count: the runbook said 333 based on an older snapshot; actual count is 333 (not 301 as CLAUDE.md reports). CLAUDE.md's test count is stale.
- npm install required lockfile regeneration — the Mac's lockfile resolves against Apple's internal registry. Cross-machine sync should use `--registry https://registry.npmjs.org/` or a clean lockfile per machine.
- Node v20 vs v22 mismatch is a soft warning only (undici EBADENGINE). No test failures attributable to it.
- KV-cache benefit is real but modest (50% prompt_eval reduction). Worth investigating whether Ollama 0.22.1's cache_prompt behavior differs from the version the M3.5 prompt restructure was designed against.
